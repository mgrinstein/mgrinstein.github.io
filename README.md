# moniquegrinstein.com

Personal website for Monique Grinstein — software engineer, speaker, and community builder.

Includes pages for About, Projects, Tech Articles, Speaking, and Contact.

## Tech Stack

- React 19
- React Router
- React Bootstrap
- Deployed to GitHub Pages

## Development

```bash
npm install
npm start
```

Runs locally at [http://localhost:3000](http://localhost:3000).

## Deployment

Automatically deployed via GitHub Actions on push to `main`. Can also be triggered manually via workflow dispatch.
